# Personal-phone final check (pending)

The trained candidates are selected on the new HaGRID validation cohort. Personal iPhone photographs must not enter the training folder or select a checkpoint; they are reserved for a final qualitative/labelled check after training.

Provide JPEG/PNG photos for fist, open palm, peace and thumbs up. Begin with one clearly visible full hand and a small margin, then add a different background/light or palm orientation if desired. Use the same declared crop protocol for all models. The Studio now supports square, tall and wide ROIs and shows the exact gray-letterboxed input used by the model. It does not automatically find a hand.

Record true gesture, chosen crop, selected model/version, predicted class, probability distribution and any explanation failure. A handful of personal photos is a field check, not a reliable general-population accuracy estimate. Do not choose only successful photos for a performance claim. If these examples later become development/training data, collect a fresh personal holdout for the next final evaluation.

Upload requests remain memory-only. If the owner explicitly saves a local labelled phone-test folder for reproducibility, keep it private and separate from data/expanded and all train/validation manifests. Nothing is sent to an external inference API.

After the personal check, refresh the laptop ZIP and demo as needed. Existing exports/gesturelab-laptop.zip and the silent3:49video are the earlier three-model snapshots, not evidence of this new version. No external transfer/publication is performed automatically.
